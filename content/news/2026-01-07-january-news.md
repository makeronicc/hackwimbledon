We had a bit of an unexpected interruption in service last year. More to come on that. For now - we're back!

The first meetup of the year is on Sunday 11th January, between 12pm and 4pm at [Wimbletech](https://www.google.com/maps/place/Wimbletech/@51.4225211,-0.2077478,17z/data=!3m1!4b1!4m6!3m5!1s0x487608b7a9d7b0fd:0xb5a23e5d378b85ee!8m2!3d51.4225211!4d-0.2077478!16s%2Fg%2F11bbrmmqkh?entry=ttu&g_ep=EgoyMDI2MDEwNC4wIKXMDSoASAFQAw%3D%3D).

If you're planning to come along, please [sign up on our lu.ma event page](https://luma.com/f8pfrny3) so that we know to expect you. You can also [join our Discord server](https://discord.gg/py5VZarC2u) to chat with us ahead of time (or afterwards, or during - we try to run a stream during the session so that folks can join in remotely). You can drop us [an email](mailto:hackwimbledon@gmail.com) if you need to do so.

Bring a laptop / computing device, and if you have a maker project you're working on, bring that too - we also have some boxes of components to share if you're looking to learn something new. Also, [Andy](https://andypiper.co.uk) is intending to talk a bit about a holiday project: getting [Home Assistant Green](https://www.home-assistant.io/green/) up-and-running (Andy is a little bit obsessed with it right now).

Still getting things into shape with the website, but we're back [on Mastodon] and we're going to work on fixing the various channels and code repositories to be a bit more consistent.

We're going to be sharing more events [on lu.ma](https://luma.com/hackwimbledon) as soon as we have them in the calendar.
